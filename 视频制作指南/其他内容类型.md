# 其他内容类型

## 1. 互动测试图：「测测你最适合养哪只猫」

小红书互动帖：评论区输入 5 个选项，@ 账号查看答案。案例：[内容案例/图文/测测你最适合养哪只猫/](../内容案例/图文/测测你最适合养哪只猫)（@豆包版）。

**结构（7 张 3:4，1080×1440）**：封面 → Q1 回家 → Q2 睡觉 → Q3 零食 → Q4 陪伴 → Q5 第一直觉 → 评论区交答案。

- 参考原帖的结构，但**选题角度和选项不要照抄**。原帖问的是雨夜、眼神、声音，我们换成养猫的日常：下班开门、夜里睡觉、想吃零食、加班陪伴、希望它说哪句话。
- 每题 4 个选项，每个选项配一张三花猫做这个动作的小图。
- 风格来自本仓库 [内容案例/](../内容案例) 里的猫咪性格对照图：淡色底（5 题各一种：薄荷绿、粉、天蓝、蜜桃橙、柠檬黄）、粗黑边、像素气泡、黄色小标签。
- **主角是素材库里的三花猫**，用它的真实精灵当参考图，提示词里写「只出现三花猫」。
- 答案对应（设计时的内部约定，图里没写）：A 黏人热情型、B 安静独立型、C 机灵有脾气型、D 佛系懒散型。用户的机器人按字母出结果。
- 生成方式同 APP 功能图：gpt-image-2 `edits`，1152×1536 → 1080×1440。

**用户的修改**：

1. 删掉 Q1–Q5 底部那一行「凭第一直觉选，别犹豫 →」。第 7 页底部相同的那行也一并删了。
2. 封面底栏和第 7 页评论框里的账号：先 @点点，再出一版 @豆包。
3. 这些修改是在原图上**局部编辑**，没有重画，所以其余文字、猫、小图保持不变；`raw_v1` 留作回退。

**教训**：

- 模型会在一个选项里画出两只主角（Q4 C 项出现两只三花猫），逐页放大检查「主角是否只有一只」。
- 模型会多加没要求的页码（评论页多了一个「10/10」）。
- 字是模型画的，发布前再扫一遍错字。
- 账号名是占位符，发之前和用户确认。

## 2. 猫猫行为大赏（反应视频）

把用户自己的 10 条 AI 猫短视频（repo `hokeem/bellvtrix-ai-top10`，版权已确认）套上一个像素小橘猫做点评。

- 开头约 1.25 秒像素标题卡「猫猫行为大赏！」，小艺配音（音高 +50 Hz、语速 +30%）。
- 然后硬切到**原视频，带原声**。
- 主持人是素材库里的小橘猫，原样使用，缩小到约 200 px 宽，放在右下角，**不加边框、不加窗口**。它只通过动作（摇摆、倾身、跳、抖）和像素气泡反应。
- 用户否掉过：改脸、爪子捂眼（看起来像戴眼镜）、反应窗口边框。
- 结尾把最后一帧压暗，弹出猫在 logo。
- **画质**：按原片的原生 720×1280 / 24 fps 输出，**不要重新缩放**。取帧时轻度锐化，x264 crf 12、`-tune film`。
- 封面：原片画面，3:4，上采样到 1080×1440 加轻度锐化，**不加字、不加马赛克**。
- 敏感镜头（比如竖中指）要加像素马赛克 + 消音。先逐帧看清动作再写梗。

## 3. 像素互动小游戏

两种机制：暂停挑战（3 帧封面、3-2-1 倒数、13 帧一轮、分档结果、1 帧稀有结果）和「小猫躲在哪？」捉迷藏。

### 视觉

- 画面必须是**真正的低分辨率像素画**：原生约 270×360 或 90×120 格，放大 ×4 或 ×12 用最近邻。固定调色板，1px 黑色描边，用抖动做过渡。
- **整个场景（包括背景道具）要用同一张网格**，和角色同一尺寸。道具少而大，一两种阴影，墙/天空用抖动条纹，地板用棋盘格。
- 被否掉过的：代码画的高分辨率形状（猫的位置不真实、盘子粘在一起）、扁平矢量环境和泡沫（「建模太垃圾」）、细线条背景配粗像素角色（「粗制滥造」）。
- 要真实场景：洗碗就是真厨房水槽，不是路边。
- 「暂停挑战质感」：大号描边像素状态字（READY? / GO! / TIME UP! / FOUND IT!）、震屏和闪光、8-bit 循环音乐 + 街机音效。**不要顶部 HUD 条**（用户删掉了），**字幕用普通描边像素字**，不要 RPG 对话框。
- 封面：描边像素标题直接压在场景上，没有深色底条；右上角小 logo。

### 捉迷藏玩法（用户指定）

1. 猫脸特写：「我们来玩捉迷藏吧……倒数三秒钟」，然后全黑，口播三、二、一。
2. 「好啦！可以开始找咯～」，然后 5 个地点**都**有声音/动作：4 个干扰项（鸟、仓鼠、老鼠、青蛙）+ 猫。猫的唯一破绽是尾巴。
3. 画面角标 ①–⑤，5 秒倒计时条，口播请观众在评论区交答案。
4. 倒数后依次揭晓每个干扰项，**猫最后揭晓**。
5. 提示要真的看得见：猫的身体某一部分每次露出约 0.5 秒，每个干扰项也有自己的露面，保证公平。
6. 猫在开头跳进画面；小艺配音，可爱语气；无 BGM。

## 4. 温暖小故事

对标 Wild Universe 的领养类视频（《假如你领养了一只总摔跤的猫》《如果你领养了那只没人要的老猫？》）。**不是炸裂升级，而是安静的情感叙事。**

- 有名字的猫（汤圆）+ 一个讲故事的小计数器（「第 N 夜」「已住 N 天」）：被拒绝 → 到来 → 小进步 → 计数器兑现 → 一句价值观。
- 默认版式 3:4，约 60–66 秒，12 个镜头。
- 旁白像「婉婉道来」：短而完整的句子（主语 + 动作，6–16 字），用「然后 / 终于 / 后来」连接，重复一句节奏句（第一夜 / 第二夜 / 第三夜），语速约 4.5–5 字/秒，结尾重新解释一开始的担心（「它不是不想进来，只是等了很久，才敢相信」）。
- 否掉过：残缺名词短语的版本（太跳）、很长的一气呵成的句子。
- 每个镜头都配口播，不要只有字幕。
- 声音：小小（Xiaoxiao）和小艺都做过样本。**按句子用有效采样 RMS 归一化到约 −15.2 dB**，不要对 1–2 秒的 TTS 片段做单遍 `loudnorm`，会得到 −29 到 −39 dB 的怪音量。FX 在口播下压 9 dB，最后两遍线性 loudnorm（I=−16, LRA 2.5）。
- 不加预告，计数器小而有意义。
- 目前没有放案例视频，脚本思路见上。
