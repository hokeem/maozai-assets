# 猫在 APP 功能介绍（图文 + 视频）

猫在是一款桌面宠物 APP：给自己的猫拍几张照片，它就住进电脑桌面，保留猫的全部习性。介绍它的内容有两种：小红书图文（5 张）和一条介绍视频。

### 风格：像素窗口（用户选定，「就这个质感」）

- 淡蓝色像素风 OS 窗口，深蓝 1px 描边，紫蓝色标题栏，上面有黄色月牙和 3 个斜面按钮。
- 宽体像素字，标题放在窗口里，副标题是一个斜面按钮。
- 下方三分之二放**截图卡片**：深蓝描边 + 硬阴影，卡片之间留 ≥50 px 间距，**不重叠**。
- 小猫、恐龙是扁平像素精灵，探出卡片边缘。
- **不要**：光泽气泡、圆滑字体、发光、渐变投影。边缘要硬。

旧版是气泡风格（粉彩底、棕色圆体大标题、橙色药丸副标题），已被替换。

### 生成方法

用 gpt-image-2 的 `/v1/images/edits`，尺寸 1152×1536（3:4），质量 high，再缩到 1080×1440。每页的参考图 = 2 张风格参考 + 真实截图 + 品牌角色。**文字要在提示词里逐字给出。**

### 返工教训（每条都是用户指出过的）

1. **别把用户给的第 4 张风格参考（浣熊/老鼠/老虎贴纸）传进去**，模型会把这些动物画进成图。只传 2 张风格图，并在提示词里写「只能出现品牌角色（橘猫、灰猫、三花猫、绿色小恐龙），不要浣熊」。
2. **真实照片小猫会被重画。** 论文截图里的灰白小猫曾被画成奶油色。提示词里要精确描述它的位置和样子（「右下角、尾巴翘起、不要替换或放大」），出 2 版挑一版没变的。
3. **壁纸用粉彩渐变**，否则模型会自己画一片黑色星空。不要加笔之类的道具贴纸。
4. **标签要和截图一致。** 小猫从猫在菜单窗口跳到「论文」文件夹上，标签是「跳到你的文件夹上」，不是「跳上任意窗口」。
5. **截图里的 UI 状态要核对。** 模型曾把「社区/通讯录」选中的 tab 翻转，提示词里要写明选中状态。
6. **不要密、不要重叠、不要整面文字。** 论文页满屏文字被用户否掉，改成桌面上自由走动的原图。
7. 截图里有一行淡淡的个人水印（拼音 + 时间），成图里看不出来；UI 上的猫名「1422」「元宝」是真实界面，可以保留。

## 二、介绍视频（9:16，1080×1920，约 59 秒）

案例：[内容案例/视频/猫在APP介绍_v1_59秒_9比16.mp4](../内容案例/视频/猫在APP介绍_v1_59秒_9比16.mp4)

流程：

```
钩子（文件夹视频，真实小猫）
→ Logo
→ 桌面（菜单、小组件、自由走动，穿插文件夹和窗口跳跃视频）
→ 领养（上传照片）
→ 旅行（打包 → 出发 → 新照片 → 看照片）
→ 写信
→ 朋友圈
→ 结尾 Logo
```

做法：

- 真实小猫直接用素材库里的**桌面演示视频**；只有图片素材的地方，做拼接和过渡（用马赛克方块转场）。
- 像素窗口风格，和 5 张图保持一致。
- 字幕是像素字（Fusion Pixel 12px，OFL 协议），逐短语对齐口播。
- 旁白：小艺（Xiaoyi，edge-tts）；音乐：合成的芯片音乐 BGM + 音效，三者混音。
- 结尾旁白：「让你的小猫，真的住进电脑」。

渲染：Python PIL 逐帧画 → ffmpeg 合成，不走浏览器。

### 用户的反馈

- **Logo 必须抠图。** 原图有蓝色底板和黑色圆角，要去掉：按颜色 + 洪水填充 + 取最大连通域，得到透明底的 logo。
- **「猫在APP」这几个字同屏只出现一次。** logo 页上如果按钮里已经有字，就不要再叠字幕；结尾旁白不要再念产品名。
- 小猫精灵**不要重新量化到「原生网格」**，会丢眼睛。用裁掉透明边的原始 PNG。

### 可以继续调的

时长压到 45 秒左右、换旁白声音、做 3:4 版本。

## 三、工具坑

- 系统自带的 `edge-tts` 会 403，用 `pip install --target /tmp/edgetts_new -U edge-tts`，运行时带 `PYTHONPATH`。
- 如果用 `OPENAI_API_KEY` 环境变量报无效，向用户要密钥，放在内存盘文件里，不要提交。
