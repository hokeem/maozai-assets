# 制作流程与踩坑清单

每一条都对应用户真的指出过的问题，每次渲染前过一遍。用户看视频是**一帧一帧**看的，他们对空间逻辑（谁在谁身上、脸看不看得见）比对特效敏感得多。

## 通用流程

1. **先看参考原片，抽帧 + 频谱**，理解节奏和镜头逻辑；复制**速率与镜头逻辑**，不只是外观。
2. **先出脚本（表格：秒数 / 节奏 / 画面 / 口播 / 计数）给用户确认**，再做。选题不确定时给 3–4 个选项。
3. **先出模型/封面/测试帧**，用户点头后再做整片。
4. 渲染前，每个镜头预览 2–3 帧（**全分辨率**），按下面的清单检查。
5. 整片渲染后看总览图，再抽查全分辨率帧。
6. 交付：视频 + 封面放同一个 gofile 文件夹，回复里给链接，写明检查过什么、哪些没做。
7. 迭代时保留旧版（`v1/`、`raw_v1/`），方便用户退回。

## 视频渲染前清单（假如 / 每秒翻倍系列）

1. **猫群要整齐**：整排、整环，间距 ≥ 一只猫宽。不要随机堆。
2. **品种要多**：12 个品种混用，不是 2–3 种颜色。
3. **计数器要大、要清楚**：不要带框的小面板；全宽顶部进度条 + 粗描边大字。
4. **主角的脸每个镜头都要看到**：检查摄像机和脸之间有没有床头、显示器、猫。
5. **姿势要和口播一致**：「猫在你身上 / 动不了」= 恐龙**平躺**，猫站在它身上；不是恐龙站着、猫在前面排队。每一句口播都问一遍「画面是字面地这么演的吗」。
6. **猫不要叠在猫上**：一层，并排。不要金字塔、猫塔。
7. **口播 1.2 倍速**：用云希 +38%~42%；镜头拉长，不要删句子。
8. **封面**：主角要大、做这一集的关键姿势、周围是很多只做同一件事的猫。
9. **版式**：视频和封面都是 3:4（1080×1440）。
10. **画面一改，口播就要改**：不再有「猫山」了，对应的那句话就要重写、重生成。
11. **字幕窗口要整个落在对应的镜头内**，不要字幕出现时画面已经切走。
12. **模型不要穿模**：猫和物体、物体和物体。跑碰撞检查，0 个重叠才算过。
13. **标签/单位逐个看一眼**：km 和 m 搞混会把月亮画到地球上。
14. **对比物太小就放大**，让参照物占屏 70%–85%。
15. **真正的速率**：先确认参考片翻倍的是体重、长度还是别的；每秒都要重缩放整个世界，说明速率读错了。

## 声音

- 旁白：每句按有效采样 RMS 归一化，再混音。**不要**对短 TTS 片段做单遍 `loudnorm`。
- 混音：FX 在人声下压约 9 dB（BGM 约 8 dB），最后两遍线性 loudnorm（I=−16, LRA 2.5）。
- 峰值检查：看 `astats` 的采样峰值，再加 `alimiter`；AAC 之后 ebur128 的 Peak 可能显示 >0 dBFS。
- BGM：原创合成，不用别人的音乐。幽默风格；人声下压低。
- 要不要 BGM 先问，或者同时给带 BGM / 纯音效两个文件。

## 代码坑

| 坑 | 解法 |
|---|---|
| InstancedMesh 没有成员时仍在原点画一个 scale=1 的巨猫 | 设 `m.count = idx.length` |
| `char()` 已经缩放过内部网格 | 外面的 group 只乘普通系数，不要再乘 DS |
| 用 python/sed 打补丁时在一行 JS 链中间加了 `// 注释` | 会把后半行全注释掉，动画角色凭空消失。注释放行尾或单独一行；补完用 `node --check` + 渲染一帧 |
| `open(f,'w').write(open(f).read())` | 先截断后读取，文件被清空。先读到变量再写 |
| 在 `.find()` 谓词里取随机数 | 每次调用结果不同，逻辑会乱 |
| 脚本拼接顺序（`main.js` 由多个文件拼） | 先覆盖、后调用；HUD 在 scene 之后；end.js 最后 |
| 竖屏下相机 fov 和位置 | fov 50 并拉远；台阶从侧面拍 |
| 体素头部偏移是小数 | 鼻子、腮红、闭眼线会错位，用整数 |
| 单个对象大于猫 | 会被裁出画面，停在 |x| ≲ 3 的位置 |
| 无头 Chromium 的 WebGL | `--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist` |
| 逐帧渲染很慢 | 6 个分片并行；`FROM=… TO=… SHARD=i NSHARD=6` 可以只重渲一段（帧号 = t×30） |
| HEVC / Playwright | 最终输出用 H.264 + AAC |
| 飞书文件 > 30MB | 压到 30MB 以下再传（如果走飞书） |

## 图文类（gpt-image-2）

- 用 `edits` 接口，传风格图 + 真实截图 + 品牌角色；文字逐字写进提示词。
- 只传需要的参考图；多余的动物参考会被画进成图。
- 每页放大看：主角数量、错字、多出来的页码、被改动的截图内容。
- 改一两处文字或删一条栏时，用「在原图上编辑」的方式，其余不动；先在一页上试，再批量。

## 版式与素材

- 3:4（1080×1440）是默认。不要把 9:16 裁成 3:4，要重新排版。
- 真实小猫视频用原比例，不够补边，不裁。

## 交付

- **默认上传 gofile.io，回复文件夹链接。** 视频、封面、总览图分别放好，只放用户要的文件。
- gofile 免费文件夹有保存期限，提醒用户尽快下载。
- 提到的文件路径写清楚；未上传的版本要明说。
