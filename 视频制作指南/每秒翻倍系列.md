# 「每秒翻倍 / 缩小」系列

参考 Bloop 的小红书视频：《橘猫每秒重一倍》（10 万+ 赞）、《呼噜每秒大一倍》、《喝水每口翻倍》。参考链接：https://xhslink.cn/o/ATUfeYa5BKh

和「假如」系列不同：**猫基本静止，一个量按固定速率翻倍或减半，用真实物体当刻度。** 没有口播。

## 先想清楚「到底在翻倍什么」（缩小篇 v1→v2 的教训）

参考片翻倍的是**体重**，不是身长。体重每秒 ×2，身长每秒只 ×1.26，所以猫是慢慢变大的，场景基本不动。

缩小篇 v1 把「每秒缩小一半」理解成身长，结果猫要么消失、要么只能让整个世界围着一只不变大小的猫往外冲。**当你发现每一秒都要把世界重新缩放一次，说明速率读错了。**

做之前先回答：参考片里的数是什么量？画面里这个量对应什么？

## 画面逻辑

- **一个固定的环境 + 1–3 个对比物**。地面要么没有，要么一直不变。后来改成「每段一个真实场景」：篮球 → 篮球场，手机/老鼠 → 客厅，鸡蛋/核桃/硬币 → 餐桌，蜜蜂 → 花园，米粒/蚂蚁 → 格子桌布，沙 → 沙滩，盐 → 厨房台面，螨虫 → 床单，头发 → 浴室，花粉 → 花园。
- 对比物用**真实大小**的体素模型。缩小篇从篮球、手机、老鼠、鸡蛋、核桃、硬币、蜜蜂、米粒、蚂蚁、沙、盐、尘螨、头发，一路缩到花粉（约 46 秒）。
- 猫缩小时对比物持续出现；每段结尾用 0.9 秒推镜把猫恢复到可见大小，再换新物体。
- 不要走到病毒、蛋白质、DNA、原子。用户嫌「后面太多、太杂」，微观段只到花粉。
- **「大小」指坐姿身高**，不是身长。坐着的猫 30 cm 高，比篮球大才对；用身长（50 cm）比，画面和文字会对不上。
- 猫在对比物旁边要**做事**：坐在篮球旁、睡在手机上、从老鼠身上走过、骑在蚂蚁上、走头发当独木桥。字幕写画面上正在发生的事，不是只贴尺寸标签。
- **模型之间不能穿模**，包括猫和物体、物体和物体。做一个体素碰撞检查，按 0.05 秒步长扫整段视频，结果必须是 0 个重叠帧。

## HUD 和字幕

- 左侧 HUD：主数字（体重/尾巴长度，大号衬线）、对比行（比…还大 / 和…差不多大 / 比…还小，**用当前画面实时算出来**，别写死时间表）、副数字（身长、饭量、尾尖速度）、红色「×½ 每秒」或「×2 每秒」胶囊。
- 双语字幕：英文斜体衬线 + 白色药丸底中文，「第 N 秒：……」。N 由字幕起始时间自动生成。
- 标题卡：英文 + 白框，橙色关键词。
- 场景切换用一次白闪。

## 尾巴篇的特殊做法

- 尾巴长度 L = 0.3 m × 2^(t−2)，每秒长一倍。参照物按真实阶梯：汽车 → 波音 737 → 埃菲尔铁塔 → 哈利法塔 → 10 km → 100 km → 国际空间站 → 地球半径 → 绕地球一圈 → 光速/月球 → 17 光秒 → 金星 → 太阳。
- **时间拉伸（story-time dilation）**：用户要求字幕说「比一架波音 737 还长」时，尾巴刚好超过飞机一截，不要长太多。做法是在每个地标附近拉伸故事时间，字幕窗口 1.25 秒内尾巴从刚好等于参照物变成 ×1.15；两个字幕之间用 2.3 秒的「快进」（Hermite 曲线），摄像机跟着尾巴拉远。
- **对比物要大**：参照物占屏 70%–85%，汽车 8.5 单位、737 9 单位、铁塔 9 单位。高的模型和尾巴放右边（x ≥ +1.6），左边留给 HUD。
- 太空场景用图标（国际空间站、月球、太阳），飞机缩略图标注「示意」。
- 地球按真实半径画；尾巴绕地球一圈时地球被环绕，这是封面素材。
- 单位 bug：km 和 m 混用会把月亮画到地球上，**每个标签都要看一眼画面**。

## 封面

尾巴篇封面返工了 4 轮，用户的要求：

- 猫的主体要大，有「怼镜头」的感觉；头正对镜头、**歪头卖萌**。
- 地球也要大，尾巴把地球环绕起来。
- 文字排版和位置不要跟上一张图相似。
- 「会怎样」不要做成小标签，还是普通文字。
- 「尾巴每秒长一倍」放一行，「会怎样」放一行。
- 不要猫在 logo。

## 音频

- 无口播。参考片是密集音效 + 每秒一次的滴答声。
- 每个视频给两个文件：`_bgm`（原创合成 BGM）和 `_sfx`（只有音效）。
- 校验：用 `astats` 看采样峰值，加 `alimiter`。ebur128 在 AAC 之后可能显示高于 0 dBFS，不等于真的削波。

## 管线和代码

`base.js`（相机、光、猫姿势）+ `objs.js`（对比物体素模型）+ `hud*.js` + `scene*.js` → `main.js`，渲染分 6 片。
**拼接顺序很重要**：`MK.*` 的覆盖要放在 `stream()` 调用之前；尾巴篇里 scene 要在 hud 之前，`end.js` 放最后。

猫模型见 [猫咪3D建模规范](猫咪3D建模规范.md)，缩小篇和尾巴篇用的是更细的 `bloopcat.js`。
