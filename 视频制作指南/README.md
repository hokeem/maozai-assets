# 猫在 · 内容制作指南

给其他 agent 看的入口文档。读完这一页，你应该知道：我们做哪几类内容、每类长什么样、该读哪份文档、案例文件在哪。

> 2026-11-22 整理，来源是 2026-11-18 至 2026-11-22 这一周的实际制作与用户反馈。
> 每份文档里的「用户反馈」都是真实返工原因，请当规则看，不要当建议看。

## 先说共同规则（所有内容通用）

1. **版式默认 3:4 竖屏，1080×1440。** 视频和封面都是。「温暖小故事」「假如」系列一开始做过 9:16，用户后来明确要求改 3:4。只有 APP 介绍视频保留了 9:16（1080×1920），因为用户当时没提。拿不准就问。
2. **不裁剪、不缩放原素材的画面比例。** 真实小猫视频、截图都按原比例放进画布，不够的地方补边，不要 `crop`。
3. **猫是产品的主角。** 品牌角色只有四个：橘猫、灰猫、三花猫、小恐龙，在 [品牌角色/](../品牌角色)。小恐龙一般演「你」。不要混入浣熊、老鼠、老虎等别的动物。
4. **风格克制，不堆特效。** 用户反复否定过：发光、粒子、碎片、HUD 堆叠、多种风格混在一起。一屏只放一个主意。
5. **画面要字面地对上文字。** 口播说「机场被猫毛盖住」，画面就要看到机场被盖住。这是返工最多的一类问题，见 [制作流程与踩坑清单](制作流程与踩坑清单.md)。
6. **逐镜用全分辨率检查，再交付。** 缩略图总览会漏掉大部分问题。
7. **交付走 gofile.io，回复里给文件夹链接。** 视频和封面放同一个文件夹。
8. **图文类内容用 gpt-image-2 生成。** 调用 `/v1/images/edits`，参考图 = 风格图 + 真实截图 + 品牌角色，文字要在提示词里逐字写出。密钥向用户要，不要写进仓库。

## 内容类型一览

| 类型 | 一句话 | 版式 | 文档 | 案例 |
|---|---|---|---|---|
| **「假如…」系列** | Wild Universe 式的升级推演：一个荒诞前提，后果一层层炸开，最后停在极端画面 | 视频 3:4，约 50 秒，真人口播 + 双语字幕 + 幽默 BGM | [假如系列](假如系列.md) | 掉毛、踩奶、拉屎 |

| **APP 功能介绍** | 用真实截图和真实桌面小猫视频介绍猫在 APP | 图文 5 张 3:4；视频 9:16 约 1 分钟 | [APP功能介绍](APP功能介绍.md) | 5 张图 + 介绍视频 |
| **互动测试图** | 「测测你最适合养哪只猫」，评论区交答案 | 7 张 3:4 像素风图 | [其他内容类型](其他内容类型.md) | 7 张图 |
| **猫猫行为大赏** | 把用户自己的 AI 猫视频套上像素小橘猫点评 | 视频 9:16，原视频原分辨率 | [其他内容类型](其他内容类型.md) | — |
| **像素互动小游戏** | 暂停挑战 / 小猫捉迷藏，评论区交答案 | 视频 9:16 | [其他内容类型](其他内容类型.md) | — |

## 3D 方块猫

**主模型是「立体方块猫」`cat3d.js`**：「假如」系列从第 3 集起用它，以后新做的 3D 猫视频也以它为准。这个模型经过三轮返工才定下来，最终版代码在 [模型代码/](模型代码)。

「每秒翻倍」系列因为要强参考 Bloop 的橘猫，另有一只更细密的体素猫 `bloopcat.js`（保留粉鼻子和白嘴套，仍然没有嘴线）。它是这个系列的变体，不是主风格。

外形规则、被否决的版本、怎么用，见 [猫咪3D建模规范](猫咪3D建模规范.md)。

## 案例文件在哪

案例放在素材库原有的 [内容案例/](../内容案例) 下，可以直接打开 mp4 看：

- `内容案例/视频/` ：4 条成片（掉毛、缩小一半、尾巴长一倍、APP 介绍）
- `内容案例/图文/` ：3 张「假如/翻倍」封面、5 张 APP 功能图、7 张测试图
- `内容案例/脚本/` ：3 份脚本（掉毛、尾巴、踩奶），写法照着抄

小红书上的参考原片（Wild Universe、Bloop）是别人的作品，没有放进仓库，只在各文档里留了链接。用之前先看一遍，复制它们的**节奏和镜头逻辑**，不要复制画面和原话。

## 这一周的迭代记录（给你判断「做到哪一步算够」）

| 内容 | 版本数 | 最大的一次返工 |
|---|---|---|
| 3D 方块猫模型 | 3 版，最终用 v2 | 第一版「一点都不像猫，不可爱」 |
| 假如·掉毛 | 脚本 2 版，视频 2 版（无 BGM → 带 BGM） | 用户指定了结构：直接说后果，不要铺垫 |
| 假如·踩奶 | 视频 3 版（含最终的 3:4 版） | 猫不能叠在一起；恐龙脸必须露出来 |
| 假如·拉屎 | 视频 2 版 | 旁白太稀，节奏要 1.2 倍 |
| 每秒缩小一半 | **7 版**，每版带 BGM 和纯音效两个文件 | 第 2 版：数学读错，应该是体重减半，不是身长减半 |
| 尾巴每秒长一倍 | 2 版，封面 4 轮 | 对比物要大，字幕说「比飞机还长」时尾巴只能刚超过一截 |
| APP 功能图 | 4 轮，共 4 套 | 风格换成「像素窗口」；卡片不要拥挤 |
| APP 介绍视频 | 1 版 | logo 要抠成透明，「猫在APP」同屏只出现一次 |
| 测试图 | 3 版（初版 → @点点 → @豆包） | 删掉底栏；Q4 有一个选项画成了两只猫 |
