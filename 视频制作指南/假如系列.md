# 「假如…」系列

模仿小红书 @Wild Universe 的「假如…」升级推演视频，用 3D 方块猫 + 猫在角色来做。选题不需要跟猫在产品有关，但必须够**炸裂**。

参考原片（只学节奏和镜头逻辑）：小红书 @Wild Universe 的「假如」系列。

## 已做的集数

| 集 | 题目 | 成片 | 备注 |
|---|---|---|---|
| 1 | 假如全世界的小猫同时在一个地方拉屎？ | 66 秒，起初 9:16 | 撒哈拉当猫砂盆。2 个版本 |
| 2 | 假如全世界的猫都想在你身上踩奶？ | 3 个版本，最终 3:4 | 猫还是纸片精灵。恐龙平躺、猫一层平铺 |
| 3 | 假如全世界的猫同时开始掉毛？ | [案例视频](../内容案例/视频/假如猫同时掉毛_50秒_3比4.mp4)，49.5 秒，3:4 | **第一集用立体方块猫**。带幽默 BGM |

脚本在 [内容案例/脚本/](../内容案例/脚本)。第 3 集的脚本最能代表现在的写法。

## 固定结构

```
钩子（一句话说完前提）
→ 首先，后果 1（直接说结果，不铺垫）
→ 并且，后果 2
→ 解决办法 ✗（人类出手，越弄越糟）
→ 后果升级
→ 解决办法 ✗
→ …
→ 最后，全地球都被覆盖 / 改变
```

- **不要**「一开始只是你家的猫，沙发上多了几根毛」这种从小事慢慢讲起的铺垫。用户明确说过要直接说后果。
- **不要**加「下一期」预告。结尾停在极端画面。
- 想加一个温情收尾也可以（第 2 集用过 3 秒「你自己的猫」），但不是必需。
- 每个解决办法都要失败，而且失败要有画面：铲雪车越铲越多、巨型吸尘器被毛堵死冒烟、织毛衣赶不上掉毛。

## 画面元素

- **屏幕上方一条贯穿全宽的进度条** 加大号描边数字做计数器。不要做成带框的小面板，小号像素字读不清。
- 红色「BREAKING」新闻条，三花猫当新闻主播，背后大屏。
- 全球弧线汇聚到目标点、卫星视角。
- 整齐的猫群：一层平铺、整排整环，间距至少一只猫宽，**绝不是随机的一堆**。前方留出一条空弧，让主角露脸。
- 猫要**混品种**，用模型里的 12 个品种，不要只有 2–3 种颜色。
- 小恐龙演「你」，脸必须在每个镜头里完整可见。

## 旁白与声音

| 项 | 规则 |
|---|---|
| 声音 | 云希（Yunxi，edge-tts），整体 **1.2 倍速**（云希 +38%~42%）。镜头拉长去配旁白，不要删旁白 |
| 密度 | 旁白占每个镜头 90%–98%。镜头时长不变就写更长的句子 |
| 字幕 | 中文按短语分块、对齐口播；完整英文折行放在下面。像素字体或 Noto Sans SC Black |
| BGM | 第 3 集起默认带**幽默 BGM**：原创合成曲，拨弦主旋律 + 大号风格的跳跃低音 + 木鱼节奏，124 BPM，在人声下方压低约 8 dB。梗点（喷嚏、吸尘器堵死）有卡点，黑暗段落转小调，结尾一个「噔噔」。不要用别人的音乐 |
| 版权 | 全部原创合成 |
| 参考 | 要不要 BGM 最好问一句，或同时给带/不带两个版本 |

合成脚本思路：Karplus-Strong 拨弦 + 合成低音 + 木鱼 → 压在口播下方 → 两遍线性 loudnorm。

## 封面（3:4，Wild Universe 风）

- 大字堆叠标题，Noto Sans SC **Black**（字重 900），粗黑描边 + 投影。
- 黄色关键词一行、红色关键动词、其余白色。
- 「假如」用同样的描边字，**不要**做成红色徽章（用户否决过）。
- 标题要**大**：第 3 集是三行，字号 138 / 150 / 250 px。
- 底部一行小字钩子：「第 N 秒：……」。
- 画面：主角大、占满画面，摆出这一集的关键姿势，周围是做同一个动作的很多只猫。例如踩奶集：大恐龙平躺，几十只猫踩在它身上。
- 案例：[封面_假如猫同时掉毛.png](../内容案例/图文/封面_假如猫同时掉毛.png)。

## 技术管线

Three.js 体素引擎 → Playwright + Chromium（SwiftShader）按帧截图，**分 6 个分片**并行 → ffmpeg 合成，口播和 BGM 由 Python 合成。

要点：
- `main.js` 是脚本、镜头、猫群、HUD 的总装；`render.mjs` 分片渲染；`make_audio.py` / `make_bgm.py` 做音频。
- 3:4 版本是**重新排版**，不是裁剪：画布高度改成 1440，字幕放在 y=1250 附近。
- 竖屏下摄像机用 fov 50 并且拉远；下降的台阶要从侧面拍，否则前排挡住后排。
- InstancedMesh 里没有成员时仍会在原点画一个 scale=1 的巨猫，要设 `m.count = idx.length`。
- `char()` 已经缩放了内部网格，外面的 group 只能乘普通系数。
- 用 python/sed 打补丁时，**不要在一行 JS 链式语句中间加 `// 注释`**，会把后半行全注释掉。补完用 `node --check` 检查并渲染一帧。
- 渲染前 2–3 帧/镜头全分辨率预览，再跑整片。

具体检查清单见 [制作流程与踩坑清单](制作流程与踩坑清单.md)。
