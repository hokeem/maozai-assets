# 假如全世界的猫同时开始掉毛？— 脚本 v2

**结构**：钩子 → 首先（后果）→ 并且（后果）→ 解决办法失败 → 后果升级 → 解决办法失败 → … → 最后整个地球被盖满。

- **格式**：3:4，Yunxi 1.2 倍速，不加 BGM，中英双语字幕，新的立体方块猫。
- **计数器**：全球掉毛量，进度条终点是「地球盖满」。

## 制作要点（按清单）
- 猫群一层平铺、排列整齐，品种混搭。
- 恐龙改成立体方块造型，没有嘴；出场的第 5、10、11 镜脸都完整露出来。
- 口播和画面一一对应：「机场」就拍飞机被粘住，「吸尘器堵死」就拍吸口塞满、冒烟，「挡住太阳」就拍天变暗、路灯亮起。
- 封面：主画面是第 13 镜毛球地球或第 3 镜猫毛雪，标题「假如 / 全世界的猫 / 同时开始 / 掉毛？」，底部写「第 X 秒：地球变成了毛球」。
